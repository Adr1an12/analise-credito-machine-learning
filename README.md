# Análise de Crédito com Machine Learning

Projeto desenvolvido em Python utilizando Regressão Logística para prever aprovação de empréstimos.

## Tecnologias utilizadas
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-Learn

## Etapas do projeto
- Importação dos dados
- Análise exploratória
- Preparação dos dados
- Treinamento do modelo
- Avaliação do modelo
- Interpretação dos resultados

## Objetivo
Criar um modelo capaz de prever se um empréstimo será aprovado ou negado com base em renda mensal, score de crédito e dívidas ativas.
